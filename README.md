# 🦈 独角鲸控制面板 (Narwhal Cloud Panel)

根据 https://api.fuckip.me/openapi.yaml （Narwhal Cloud V2.0 API）搭建的网页控制面板。
**只需填写 API 密钥即可使用全部功能。**

## 快速开始

```bash
cd fuckip-panel
python3 panel.py
```

然后浏览器打开 **http://127.0.0.1:8080**，在右上角粘贴 API 密钥（`rnm_` 开头，
在独角鲸官网 → 个人资料页生成），点「保存并连接」即可。

- 密钥只保存在浏览器 localStorage，不上传到任何第三方。
- 自定义端口：`PORT=9000 python3 panel.py`
- 仅需 Python 3 标准库，无第三方依赖。

## 为什么需要本地服务？

浏览器直接跨域调用 `api.fuckip.me` 会被 CORS 策略拦截。
本服务在 `http://127.0.0.1:8080/api/*` 提供同源反向代理，
把请求原样转发到 `https://api.fuckip.me/api/v1/*`（含 Authorization 头），
前端页面与代理同源，因此不受跨域限制。

## 文件说明

- `panel.py` — 本地服务 + API 反向代理（生产用这个）
- `index.html` — 前端单页应用
- `mock_upstream.py` — 模拟 API（仅开发联调用，普通用户不需要）

## 安全提示

- API 密钥等同于账号密码，请勿分享面板地址给他人（服务默认只监听 127.0.0.1）。
- 在「设置 → API 密钥管理」中可随时轮换/删除密钥。
